### Moodle Web Service 토큰 발급 여부 미확인

`/login/token.php`가 살아 있으나 SSO 계정에 토큰이 나오는지 확인하지 않았다.
나오면 HTML 파싱 대신 공식 API로 갈아탈 수 있어 유지보수 비용이 크게 준다.
브라우저에서 아래 주소를 열어 응답이 `token`인지 `invalidlogin`인지 확인하면 된다.

## 알려진 제약

- 자막 커버리지는 21.5%다. LearnUs 자동 자막은 최근 강좌 위주이며, 나머지는 직접 전사해야 한다.
- 접근할 수 없는 영상 94편은 콘텐츠 삭제(2022년 위주) 또는 열람 기간 만료로 복구할 수 없다.
  69편은 이미 진도 100%라 학습 기록 자체는 남아 있다.
- 첨부 파일의 기본 한도는 512 MB이며 `YONSTUDY_MAX_FILE_MB`로 조정한다. 과거 40 MB 한도에서 URL만
  기록했던 파일도 새 한도 이하면 다음 동기화에서 다시 받는다.
- 한국어 음성과 영어 슬라이드 조합은 교차 언어 정렬을 하지 않고 타임라인도 만들지 않는다.
- 현재 환경에는 GPU가 없어 Tier C(CPU)를 사용한다. GPU 환경으로 옮기면 Tier A/B를 사용할 수 있다.

## 2026-09-01 재감사

- `report` 명령을 추가했다. 한국 시간 기준 오늘 공개된 항목, 완료 상태 전환, 새 게시글과 활동,
  할 일, 과목별 완료 체크 표시 누락을 한 리포트로 출력하고 SMTP/sendmail로 보낼 수 있다.
- 동기화 간 차이를 `change_event`에 남겨 영상 진도 100%, 제출 완료, 완료 아이콘 변경을
  날짜별로 추적한다. 기능 추가 전의 과거 완료 시점은 소급해서 알 수 없다.
- 완료 상태 파서는 구형 `completion-auto-y/n` 외에 수동 체크박스, ARIA,
  `data-completionstate` 변종도 읽는다. 완료 추적이 꺼진 활동은 미완료가 아니라 별도 상태로 둔다.
- 자동 재생 워커는 현재 학기와 정상 수강 기간으로 범위를 제한하고, 대상 과목을 실행 직전에
  갱신한다. 재생 종료 뒤 진도표를 재조회해 100% 또는 완료 체크가 없으면 서비스 실패로 남긴다.
- 스케줄러 시간 비교를 KST로 고쳤으며, 한국어 `상세보기`가 최대 시청 시간 뒤에 붙을 때
  `56:40`을 56초로 오해하던 파서도 교정했다.
- 강의 자료, 게시판 첨부, Q&A와 공지 글의 rclone 증분 업로드를 구현했다. OneDrive뿐 아니라
  SMB, SFTP, WebDAV 원격 저장소도 같은 경로를 사용한다.
  Gmail 앱 비밀번호는 계정 주인이 한 번 직접 입력해야 실제 메일이 발송된다.

## 운영 메모

- 세션이 끊기면 `python3 cli.py login` 후 **같은 명령을 다시 실행**하면 이어받는다.
- 긴 작업 중 `status`·`analyze`를 동시에 돌려도 된다(WAL).
- 요청이 몰리면 HTTP 400이 나는데, 원인은 서버가 아니라 `ubboard_read` 쿠키 비대화다.
  이미 고쳤지만 비슷한 증상이 보이면 [LEARNUS.md](LEARNUS.md#http-400의-원인-ubboardread-쿠키)를 먼저 확인한다.
- HTTP 400을 진단할 때는 서버 차단으로 단정하기 전에 같은 순간 별도 프로세스로 같은 요청을 보낸다.
  두 프로세스의 결과가 다르면 클라이언트 상태를 먼저 확인한다.
